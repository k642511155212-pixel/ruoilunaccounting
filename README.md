## Publish
Upload every file in this folder to the GitHub Pages repository root. No build step is required.

## Source fidelity
Missing textbook/source solutions are **not invented**. If the supplied source contains a solution/answer key, it remains with the source exercise text; otherwise the site preserves the question as-is.
